# 双钱包资金费对冲：合成工程验证

这批实现验证现货与合约分别记账、逐事件核算和多日运行，不包含真实市场收益研究或策略资格。所有入口只使用明确构造的2001年数据，没有行情下载、账户读取或下单能力。中国ETF的万元账户假设没有直接套入此模型。

## 已实现行为

- 模型分开保留现货资产、合约保证金、费用扣币、现金转账与未完成双腿。转账只在明确确认后改变余额。
- 资金费按原始事件时刻对实际已存在的空头结算，保留非整分钟时刻；同刻顺序为资金费、转账确认、成交。事件前后分别检查钱包和风险，不能用随后成交抹去此前风险触发。
- 决策只使用已完成的价格和20分钟容量输入。跨日核算保留本金、峰值与冷却状态；未知同步现货价格保持未知，不以旧价假装已知事件点。
- 结束退出意图在该时刻已知事件处理后、普通再平衡前生效。此前已经成交的半腿继续完成其原定修复，再退出剩余头寸。
- 输出逐事件不可变状态、分钟条件区间、账户与成交。分钟OHLC形成的区间只能诊断给定状态下的不确定性，不证明所有可能路径都安全，也不证明某条假设路径就是全局最差收益。

## 有限演练与验证

固定两日演练使用1000单位的人工资金、600/400钱包分配、20分钟预热、2880个分钟和8次构造资金费事件，得到4笔模拟成交、3次明确转账确认并完成退出。这个钱包分配、最小数量和手续费都是人工测试条件，不能追认为真实历史交易规则。

最终四个模块共90项针对测试通过，多日CLI完成；独立复核另用3项反例核对结束退出优先、已知事件现货风险和未知现货的标注。报告字段固定为`qualified=false`、`real_forward=0`。合成路径的盈亏不作为投资证据。

