# 美元配置账户的跨日运行适配

当前版本只接收明确标注的2000—2004年人工事件，不获取报价，不激活真实账户。它用于把已实现的美元账本接入分时记录和程序重启流程；真实候选、真实来源和实际费用仍需独立确认。

复用未改动的美元会计算术，单独推进开盘与收盘，不调用历史终点清仓。每月最后一个完整收盘冻结25%目标；后续第1个交易日处理卖出、第3日收盘冻结买入数量和各自预算、第4日开盘尝试买入。月中激活等待下一个正常月末。买不起整股的部分留现金；跳空不能扩大预算或把别的资产预算挪来。

开盘事件只含开盘价格，不允许带入当天收盘和成交量。每个事件的effective_at绑定固定交易时点，known_at和received_at分别说明何时获知、何时收到；未知执行状态或迟到事件拒绝推进。分红按既定30%预扣、45日延迟假设，卖款按3个后续交易日锁定。2%日亏、40%连续高点回撤和5个完整空仓日规则沿用原账本。

每个已确认事件记录输入、前一事件指纹和账户快照指纹；独立尾记录保留已确认数量和最后指纹。重启从原始事件重建现金、股份、结算款、分红应收、FIFO与风险状态。文件缺失、篡改、代码变化、遗留写锁或未确认尾记录会停止读取；没有自动删除证据或回退旧持仓。不承诺操作系统物理断电耐久，也不防止有人同时恶意改写所有本地文件。

运行入口：

```powershell
python scripts/run_us_allocation_paper_journal.py --journal <人工账户目录> create-artificial --manifest <人工日历与暖机文件>
python scripts/run_us_allocation_paper_journal.py --journal <人工账户目录> advance-artificial --packet <人工开盘或收盘事件>
python scripts/run_us_allocation_paper_journal.py --journal <人工账户目录> status
```

最初的无独立尾锚版本存在删除最后事件后被当作旧前缀恢复的问题，独立复现和修复记录保留在本地工程报告。当前验证覆盖原账本完整人工前缀一致、分红付款、卖款释放、风控退出、跨进程恢复及冻结预算。人工运行不增加真实前向天数或候选数量。
