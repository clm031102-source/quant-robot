# 1万元账户：货币ETF现金申赎来源审查

2026-09-21。候选为159001易方达保证金货币A，状态为**合同层面支持小额申赎，历史执行来源仍不足**。
本次没有读取每日收益序列、计算策略收益或登记第七项市场检验。实际完成的研究仍为六项，
已验证净正EV策略仍为0，新增真实纸面观察日为0。

## 机制与规模

研究的是货币市场利息通过基金现金申赎形成的持有收益，不是二级市场溢价套利或择时因子。
选择依据为交易所确认的现金申赎机制和一份起的申赎单位，没有按新读取的收益排名选基金。
它至多成为现金管理仓位或比较基准，不能把用户要求的盈利策略目标改成现金管理。

2015、2023及2026招募书均载明：场内最小申赎单位为1份，每份申赎价格100元，
正常情形不收基金申购赎回费。上述单位只用于现金申赎，不能用于二级市场买卖。
合同仍设置基金及单账户每日额度，超过额度可能拒单；销售机构也可能另有申购限制。

本金仍为10000元，单仓含费上限1000元。若仅作每笔固定收费0/5/10元的算术情景，
可申购份额分别为10/9/9份，申购支出分别1000/905/910元。
后两情景往返费用为10/20元，需要900元本金在整个持有期取得超过1.11%/2.22%的现金收益，
才能覆盖这项费用；这不是年化预测，也没有包含其他收费、收益取整、特殊赎回费或拒单。
基金免申赎费不能证明券商及分红转账免费，原二级市场佣金和滑点假设也不能直接冒充一级申赎费率。

## 已核对的规则

| 事项 | 原件证据与含义 |
| --- | --- |
| 每百份收益 | A类按每100份基金份额披露已实现收益；每份100元，不能把它当作每10000份收益直接计算。2015招募书PDF第9页，2023第10页。 |
| 收益归属 | T日申购自T+1起享有，T日赎回自T+1起不再享有；T+n是第n个交易所工作日。2015第9、72—73页，2023第9、66页。节假日处理必须与完整每日收益口径对齐。 |
| 早期支付 | 2015按日分配、按月支付；每月15日或顺延工作日支付上月收益。全部退出另结未付收益。2015第72—73页。 |
| 后期支付 | 2023及2026 A/B类按日分配、按日现金支付。2023第66—67页，2026第70—71页。变更生效日尚未查明。 |
| 2019结算修订 | 2019-10-21起，全部赎回或卖出后未付收益的清算、交收上限从T+2/T+3提前到T+1/T+2。修订公告第4—6页。这并非月付改日付的证据。 |
| 金额精度 | 2015载明分配到分、去尾余款再分配；后期A/B条款仅明确精度0.01元。不得套用C/D类的红利再投资取整条款。 |
| 负收益 | 可以记录并追索负收益，不能因为申赎面值100元就假设没有经济亏损。 |
| 特殊费用 | 后期合同规定特定流动性及负偏离情形下，对超过基金总份额1%的赎回部分收取1%强制赎回费。不能把正常零费率写成无条件零费率。 |

2014交易所技术指南记录了转为ETF后的T+1 DVP及资金可用/可取差别；2019原公告显示结算规则
随后修订，故不把2014技术安排无条件回填全历史。基金收益分配的银行转账等费用由投资者承担，
券商是否具有代收代付功能也影响收益到账。这里没有连接券商或读取账户。

## 来源结果与剩余缺口

已保留5份官方PDF：2015、2023、2026招募书，2014深交所技术指南，2019合同修订公告。
另有基金身份页、3份链接脚本和2份限定公告目录响应，共11次实际HTTP请求。
来源方案和解析范围先行提交；第二次目录查询依据已留存招募书载明的2023-06-05合同更新日期，
仅查询该日，没有滚动搜索或读取收益来改变范围。

首个“调整”目录返回4项，只有2019公告涉及本基金结算修订；第二个日期目录返回2项，
仅为已留存的招募书及产品资料概要。未找到月付改日付原公告，未使用剩余PDF名额重复下载。
这两项有限目录查询不证明完整公告档案没有该修订。

基金页面暴露了有日期参数的每日收益及交易状态接口定义，但本次没有请求这些接口。
仍缺申购前可见的历史PCF、基金/账户额度、暂停状态与容量证据；交易状态本身不能代替PCF。
现有Tushare受限接口不重试。零成交不能被当作已实现收益，更不能假定每个历史申赎日都成功。

如有可信的新原始来源，下一步先补齐PCF及支付规则、费用与小数收益分配口径，才考虑冻结
独立收益检验。不能把高度相关的每日货币收益计为独立交易来抬高样本数，也不为凑30笔反复申赎。
本候选未获市场收益检验、完整账户运行或纸面晋级许可；它是来源不足，尚非负EV结论。

检索曾意外显示相关A/B/C类历史及当前经理区间表现片段，已留存暴露记录；没有用于筛选或调参。
不能称整个研究上下文对2026相关表现完全盲化。密封的本地2026 ETF行情未打开，后续独立验证
必须使用新的未见观察。官网HTML以原件形式留存，只提取身份、链接及接口定义，未提取其报价收益值。
