# 预测修订汇总到ETF：当前暂停准入

事件身份修复和离线重放已经完成，但当前不把研报修订汇总为ETF因子。暂停的原因是经济映射和历史来源仍不合格，不是合成测试失败，也不代表所有预测修订策略都无效。

## 原研究与本项目的差异

已读取Gleason、Lee（2003）[作者上传的论文](https://www.researchgate.net/publication/228170709_Analyst_Forecast_Revision_and_Market_Price_Discovery)的定义、样本与方法部分。研究对象是1993—1998年的美国个股FY1预测修订；修订量以EPS变化除以前日股价，而不是净利润相对变化。创新程度还比较同一分析师的旧预测与前日一致预期，后续表现研究到数月及一年。

因此，新模块的净利润变化字段只是可以核查的事件输出，不能称为论文因子复现。论文的年度最大分析师覆盖数，以及排除前后一天其他修订的敏感性样本，也不能未经修改就充当当日可知过滤条件。这是根据其方法作出的实施判断。

另一篇选定文献为Kothari、Lewellen、Warner（2006）的整体市场盈余新闻研究。[作者目录](https://www.mit.edu/~kothari/research.html)确认论文身份，但本轮选定的作者PDF返回404，出版社读取失败，存档预印本读取超时，未取得可完整核对的方法文本。保留这些限制，不用摘要线索给ETF设定反向信号，也不继续扩大相同文献的取件尝试。

## 实际来源缺口

| 条件 | 当前证据与决定 |
| --- | --- |
| 同目标修订 | 新入口能保留股票、机构、作者、预测期；旧规范化缓存丢失的信息不能恢复 |
| 当时可知预测 | 调用方的观察时间只做一致性校验，尚无独立历史观察认证；今日获取旧报告不能倒填时间 |
| 一致预期与覆盖变化 | 需要当时有效预测集合、退出和更正依据；每日新发研报均值不能替代存续预测集合 |
| ETF历史暴露 | [公开持仓试点](cn_etf_reported_holdings_source_review_2026-09-12.md)只有510050两份完整正文通过；356个候选标题不等于完整历史持仓。披露持仓也不等于当前篮子 |
| ETF收益机制 | 个股相对收益、覆盖结构和整体市场风险不能互换；尚未固定有依据的ETF聚合对象、方向和持有期 |

当前停止扩建依赖这些未认证条件的ETF聚合器，不下载新的研报值、不读取ETF收益、不补跑旧股票预筛。已完成工具作为独立来源资产保留。再推进这条路线需要新的历史观察证据、具体暴露来源和可审查的ETF机制，不能靠换名字、修改符号或增加窗口重开。

本轮限定两次初始检索、两篇选定方法文献；一篇取得作者上传的可读全文部分，另一篇方法正文未取回。仅复核明确的本地来源文档、模块和调度元数据，没有新增量化实验。详细边界、失败取件和决定保存在`data/reports/etf_monetization_20260911/analyst_etf_mechanism_review_20260914/`。

下一项独立评审转向**非金融实体信用扩张与后续风险补偿**，先核对经济机制及宏观融资发布/修订口径。它不借用旧LPR利差、ETF融资余额或个股资金流的实验额度，也不预设“融资增加就买入”。若仍缺可知来源或买入后收益机制，同样在来源阶段收束。
