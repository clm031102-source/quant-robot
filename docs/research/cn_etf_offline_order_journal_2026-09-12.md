# ETF 离线订单账本与故障演练

这是 P2 的第一项运行能力：合成订单可以持久保存、接收分笔成交与状态回报、在重启后恢复并核对。入口始终标记 `offline_fixture_only`、`executable=false`；没有网络调用、券商适配器、真实账户或委托提交。中央研究到模拟边界保持不变。

## 已实现的行为

- SQLite 每个指令一个事务，现金、份额、订单、费用和回报身份由同一追加事件重建；写入使用 FULL 同步，多个写入方通过事务串行化。数据库触发器拒绝修改和删除事件，重放检查序号和哈希链。
- 订单 ID 和幂等键永久占用，完成或撤销后也不能重复登记。成交 ID 在本账本全局唯一；相同回报重复到达不再次记账，身份相同而内容冲突则持久暂停。
- 已登记订单占用现金或可卖份额。买入覆盖限价剩余金额和剩余佣金，卖出同时覆盖最小分笔成交可能产生的费用缺口，以及累计费用按分舍入的中间跳点。没有成交不收费；每笔成交只补足整张订单累计佣金与已计佣金的差额。
- 重启时，待确认、已受理、部分成交、撤单中的订单全部进入 UNKNOWN；余额和成交继续保留，不自动重发。未知订单和故障均阻止新订单登记，已有成交仍可入账。
- 撤单申请不释放预留，确认撤单后才释放未成交部分。先全额成交后到达的撤单回报不会把订单改回未成交；终态之后才收到的新成交仍记账并暂停。超限价成交同样保留事实并暂停。
- 核对要求完整现金、份额及全部历史订单的状态、已成交数量、金额、费用，且快照绑定当前事件序号。数值不符、缺单、缺成交或过期快照拒绝通过；不会按快照伪造成交或覆盖余额。成功核对可清除故障暂停，不能解除操作者独立熔断。

金额使用独立的50位十进制计算上下文，避免调用方设置精度影响账目；初始金额、单笔数量的输入上限不会错误套用到累计余额、成交金额或持仓核对。本演练佣金按整张订单累计金额取比例费和最低费的较大值，再四舍五入到分。这是显式的合成费用假设，不代表已核实的券商计费规则。回报身份按数值规范化，不会把 `10` 和 `10.0000` 当作不同价格；冲突或不完整回报的规范化原请求随故障事件保存，便于追查。

## 验收入口

在项目环境运行：

```powershell
python scripts/run_offline_order_drill.py --output-dir data/reports/offline_order_drill_20260912_verified
python -m unittest tests.unit.test_offline_order_journal tests.integration.test_offline_order_recovery tests.unit.test_execution_boundary tests.unit.test_cn_etf_execution_interface_contract
```

演练目录中的 `synthetic_orders.sqlite` 必须不存在；重跑时选择新的目录，禁止覆盖旧账本。报告保存六个阶段的具体状态、现金和份额、实现与账本指纹。演练覆盖部分成交去重、撤单过程中重启、完整核对恢复、撤单与成交交错、错账暂停，以及操作者熔断独立保持。

独立进程验收分别在提交后和事务提交前强制退出：前者必须保存成交并识别重复回报，后者必须让现金、持仓和回报身份一起回滚。并发验收用两个独立连接竞争不足以同时支撑两张订单的现金，必须只有一张登记成功。哈希篡改检测覆盖改写事件正文的情况。

本批32项新增验收（28项单元、4项集成）与8项既有边界/接口检查共40项通过；构建、编译、项目扫描及可维护性基线通过。独立审查指出的累计金额核对上限、卖出费用舍入预留及已付舍入费用重复预留问题均已复现并修复。最终演练证据需与最终代码指纹对应；远程全套检查按具体提交单独记录。

## 明确剩余范围

该账本尚未接入合格策略或券商。原始 `register` 只完成余额预留和局部输入检查，并不代表风控批准。后续同日已加入可选的受控账本模式，绑定完整意图、策略版本、信号/行情时效、元数据、可卖份额及风险限额，并禁止绕过该模式直接登记；详见[完整准入验收](cn_etf_guarded_order_admission_2026-09-12.md)。未启用该模式的原始故障演练仍保持原有适用范围。

证券代码格式校验不等于确认其是 ETF；没有 ETF 主数据时不可用于交易资格判断。未启用准入的原始演练仍将初始份额和买入份额视为可用；新增受控模式依据显式合成元数据实现 T+1/T+0 和可卖份额限制。真实节假日日历、冻结份额来源及公司行为与订单账本联动仍未完成。历史模拟中的分红账本仍属另一条已注明适用范围的执行路径。高频、大规模日志性能、备份恢复、撤单超时、成交撤销/修正和真实时间运行调度仍待实现与验收。

完整合成核对是程序校验，不是外部账户真实性证明；不能把本地账本复制成快照便声称通过券商对账。哈希链能发现未同步修改哈希的损坏，但不能防止有数据库写权限的人重建整条日志，也不能独立发现完整尾部被截去；外部固定锚点与备份属于后续运维范围。

本批不增加任何真实向前模拟观察天数，不生成策略收益，不解封留出样本，不使历史淘汰候选重新合格。P1 的真实分红、复权来源及证券身份核实仍未通过；P2 也不能因本账本完成而整体标记完成。
