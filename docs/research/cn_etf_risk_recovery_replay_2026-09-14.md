## 结论

现有 `OfflineRuntime` 已能衔接受限减仓、合格收盘记录、进程重启和次日重新评估风险。本轮新增4项跨日集成测试，连同相关测试共33项通过；没有修改执行系统、风险阈值或历史研究账户实现。

[财政研究](cn_etf_fiscal_execution_result_2026-09-14.md)按照冻结的 `event_hold_conditional_cash_account_v1` 契约执行，任一风险超限均永久停止新开仓。2021-09-06的0.40元超限导致后续长期持币。该结果体现那份契约的限制，不能据此认定现有离线运行系统缺少恢复能力。本次核对也不恢复财政研究额度，不重跑、拼接或替换原结果。

## 已执行的完整路径

初始现金9010元、200份合成持仓、价格4.95元，权益10000元；单持仓上限1000元，日亏损限额60元，累计回撤限额8%。万五按每边佣金解释，最低佣金采用尚未确认的5元情景。

| 顺序 | 明确输入及观察结果 |
| --- | --- |
| 超限 | 报价升至5.002元，200份市值1000.40元，记录单持仓超限，新买入被拒绝 |
| 减仓准备 | 目标金额1000元按100份整手向下取整为100份持仓，准备卖出100份；尚未成交时仍持有200份、现金9010元 |
| 明确成交回报 | 注入100份按5.002元卖出的合成回报，扣5元佣金后现金9505.20元、持仓100份；当天继续禁止新增风险 |
| 合格收盘 | 15:00的新鲜合成报价确认权益10005.40元，订单已全部结束；记录随账本持久化 |
| 重启及次日开盘 | 关闭并重新打开运行进程，收盘记录不变；次日重新核对持仓、报价、亏损和敞口后，普通仓位超限停止可以解除 |
| 次日新事件 | 允许另一只合成ETF买入100份，准备订单并不创造成交；注入4元明确成交回报并扣5元佣金后，现金9100.20元、两只ETF各100份、权益10000.40元 |

上述权益差额由人为给定价格和费用产生，只用于核对资金守恒，不是策略收益或获利证据。所用ETF代码仅是既有合成夹具标识。

## 阻断和恢复条件

| 情况 | 已验证的行为 |
| --- | --- |
| 减仓尚未实际成交 | 持仓敞口不减少；长时间未明确的订单进入UNKNOWN，无法取得合格收盘和开启次日风险会话 |
| 已减仓但没有合格收盘 | 次日不能跳过上一交易日的参考权益；新买入被拒绝 |
| 收到无法识别的回报 | 故障保留，收盘与次日恢复被拒绝；进程重启不能消除故障 |
| 收盘合格但次日仓位仍超限 | 开盘之后、接纳新意图之前重新估值，立即保留单持仓超限，新买入被拒绝 |
| 当天亏损达到60元后价格恢复 | 当天日亏损停止仍保留，不允许以盘中反弹清除；合格收盘后次日按上一日收盘重新计算 |
| 隔夜发生亏损 | 既有相关测试确认上一日收盘到次日开盘的亏损仍计入日限额；99元示例触发停止 |
| 累计回撤达到8%后价格恢复 | 停止跨重启及交易日保留，无自动重置，次日新买入仍被拒绝 |

政策必须明确选择 `exposure_stop_action=reduce_only` 和 `daily_loss_basis=previous_session_close_v1`；旧政策的默认行为没有改变。合格收盘为冻结时段内的合成报价观察，未认证为真实官方收盘。

## 对后续建设的约束

本次具体工程核对已完成。后续优先级返回费用和资金兼容的独立经济假设，不再重复建设通用恢复模块。

新候选进入账户研究之前，先冻结风险停止的分类、减仓成交方式、下一时段的恢复条件、亏损参考、截止日未平仓处理及统计观察区间，再核对历史账户与运行规则的一致性。只需在实际候选需要时扩展账户模型，不提前重写整套历史引擎。永久退出可以是研究选择，但必须报告停止日期及实际交易样本，不能把之后的持币年数视为持续交易验证。

当前最低5元佣金只是待确认情景。1000元的买卖一轮仅最低佣金就约1%；减仓至约500元后同样10元费用约占2%。因此可恢复运行仍不解决经济优势和小额交易成本的主要缺口。
