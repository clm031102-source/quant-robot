# 数据取件恢复与510300权益来源核对

当前关闭的是限定来源的取件和组成核对缺口，尚未认证策略正EV或整体执行会计。新的单次直连已取得ALFRED预定历史版本，以及510300的分红和复权因子；系统代理、已安装SDK和默认采集适配器没有改动。

## 网络故障与空数据分别处理

相同Tushare公开文档经本机代理超时，显式直连返回正常内容；官方HTTPS接口也能返回明确的权限状态。这支持对已经失败的具体来源另行限定请求，不支持无限重试所有旧路线。公告`anns_d`直连明确返回40203权限拒绝，继续挂起，不购买权限。

本机Tushare 1.4.29的客户端文件与其安装记录指纹一致，不能因其与GitHub主分支不同就推断被篡改。用合成响应离线复现后确认：HTTP503这类布尔判断为假的响应，会被该SDK转换成无行无列的空表。复现未使用真实凭据或网络，也不能证明早期四次空表实际就是503，因为当时未保存HTTP状态。

新增`TushareSourceHttpClient`作为可复用的受限来源入口，仅支持`fund_adj`、`fund_div`、`anns_d`、`etf_limit`。调用必须明确历史日期上限、请求次数、字段及行数，客户端另限响应字节和连接/读取时间。请求只到官方HTTPS地址，不跟随跳转，不自动重试；默认遵循环境代理，直连必须显式选择。HTTP错误、供应商拒绝、解码/范围错误与成功返回的空结果分别记录，凭据不进入诊断；超出预算不再发请求。

该入口还检查返回的代码、日期、字段、行数及有限标量值。原始重复行继续保留，不自动求和或判定修订先后。默认SDK采集路径尚未切换；后续按来源合同逐个接入，并由调用入口保留冻结范围和诊断记录，不能仅靠新类存在就声称全部采集流程修复。

28项相关测试通过，含10项新增；又用4份刚取得的真实响应做离线重放，保留1087、62、184、14行，未追加网络请求。加上此前ALFRED的16项相关测试，本小时两批共20项新增测试通过。证据位于`data/reports/etf_monetization_20260911/action_source_direct_20260914/http_client_verification.json`。

## 已核对的历史范围

先限定重查510300.SH的2024-01-17至01-19复权因子及2024-01-11公告日，均取得有效响应。随后依据这项新证据，事前固定再取既有会计范围2020-01-02至2024-06-28的单ETF复权序列，以及另外3个已知分红公告日；共4次扩展请求，无重试、无行情或收益计算。

| 核对项 | 结果与限制 |
| --- | --- |
| 复权因子与日历 | 1087行、1087个日期精确一致，全部为有限正值；未将其乘入权威行情 |
| 因子变动日期 | 仅4次变化，分别为2021-01-18、2022-01-19、2023-01-16、2024-01-18，与4份既有公告除息日相符 |
| 分红金额 | 接口与公告分别为0.072、0.075、0.064、0.069元/份；以十进制核对，不误用每10份金额 |
| 登记、除息、支付日期 | 每个目标来源记录均与对应公告的计划日期一致；不是已观察的个人账户到账 |
| 重复记录 | 每件分红返回2条，共8条来源观察，对应4件已知经济事项；2024两行的净值除权日还存在空值与非空值差异 |

重复行不能让现金分红翻倍，也不能按行序认定哪条是当时版本。本次以单份已核验公告为经济事项锚点，仅认证各来源都一致的金额、登记日、除息日和计划支付日，保留全部原始观察及差异。接口没有提供足以认证原始发布时间和修订顺序的完整证据。

[Tushare分红字段](https://tushare.pro/document/2?doc_id=120)将现金分配量描述为每份金额；[复权因子说明](https://tushare.pro/wctapi/documents/199.md)提供序列，但当前未完整认证其调整算法、归一化和全部修订。因此因子变化只能辅助已有公告、连续份额报告及价格核对，不能单独证明所有事件绝无遗漏，也不能把提供商因子直接认作投资者净现金总收益。

原始响应、日历/公告指纹与交叉核对保存在同一证据目录的`action_source_crosscheck.json`。4份公告和既有价格、份额报告复用已通过的限定证据，不重复下载；保持`source_audit_verified=false`，不改写旧冻结产物或恢复研究额度。

## 后续入口与执行合同

随后将既有价格、身份、日历、现金公告、定期报告和新提供商证据做了联合核对：29份具体文件的原记录指纹一致，1087日的价格/身份引用同一组输入，4件官方现金事项与8条提供商观察对应，五个份额报告期连续。没有重跑原行情审计、解析行情价格列或计算收益。首次核对误把2022年报放在其他年报的目录下；依据已有取件记录找到原文件，原指纹一致，保留定位错误与修正，不替换来源。

此次关闭的是组成证据之间的身份、范围和文件绑定缺口。回顾研究可以使用明确的自有除息日再投资口径，不必先复刻未采用的提供商复权公式；四件毛额来源事实也不需要先获知个人券商到账。但新预注册仍须选定行动来源并明确审核“无未列示折算”的剩余覆盖假设，晚发定期报告不能进入历史预测信息集，净账户绩效仍需投资者现金、费用和成交合同。保持整体`source_audit_verified=false`，不把组成一致写成全部资格通过。证据为`joint_source_review_20260914/result.json`，下一步集中处理候选的推断和执行口径。
