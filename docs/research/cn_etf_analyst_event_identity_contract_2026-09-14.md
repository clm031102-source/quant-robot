# 研报预测事件身份与同目标匹配合同

本实现用于修复已复现的来源身份缺陷，独立于旧`analyst_report_revision_pit_prescreen`的经济假设与实验结果。现阶段仅使用合成原始响应验证，不下载研报、不读取真实预测值或ETF收益，不自动生成可交易因子。旧规范化缓存已经丢失的预测期和原始响应信息不能由新程序补造。

## 原始事件

输入必须是保留原始字节的Tushare `report_rc`成功响应，以及带时区的实际观察时间。入口保存响应指纹和行身份，拒绝重复字段、结构错误、无效股票身份、缺失机构/作者/标题、非法预测期和不可解释时间。`quarter`保持完整预测报告期，不把2024Q4和2025Q4合并。

同一预测对象按股票、机构、作者和预测报告期区分。研报身份另外包括报告日、标题、报告类型与分类；机构名称或作者改变不自动视为别名。原始响应的更新时间与预测内容形成版本，完全重复的记录可以合并并保留次数；同一身份、同一更新时间下的冲突内容必须报错。

字段语义以已读取的[官方说明](https://tushare.pro/document/2?doc_id=292)为依据：`np`为预测净利润（万元）、`eps`为预测每股收益（元）、`tp`为预测利润总额（万元）。目标价只来自有效的`min_price`/`max_price`。保留缺失值，不能用0填充。非法数值不能悄悄消失；精确小数从原始JSON读取。

## 可知时间

报告日是日期，不能凭它补造盘中发布时间。提供商`create_time`是更新时间，也不是原始公开时刻。无时区的该字段按本合同显式指定的中国标准时间解释；实际观察时间必须自带时区。

本合同采用保守下界：可用时间不早于实际观察时间，也不早于报告日次日零点（中国标准时间）。提供商更新时间必须不晚于观察时间，且不能早于研报日。原始数据缺少更新时间时保持未知，不据此认证历史版本。

今日取得的过去研报最早只能在今日观察后进入该事件序列。要还原当年可知性，另需可核验的当时观察/归档证据，不能把观察时间改成报告日。这里只验证时间的一致性，不把调用方填写的时间当作独立认证。交易日历与成交延迟属于后续候选合同。

## 修订匹配

按可用时间推进每个预测对象的状态，不按输入文件顺序差分。同一时刻首次看到一批历史报告时只建立最新状态，不批量制造过去的修订。已有状态遇到同一时刻多个新报告时，只比较先前状态与本次最新、可明确排序的状态。

只有预测对象相同、报告日期严格前进且基准无歧义，才能构成新研报修订。同一研报的提供商更正单独记为更正，不冒充新预测；迟到的更早研报不能替换最新基准。同一报告日存在不同研报、但没有可证明的先后顺序时，该对象进入歧义状态；后续明确更晚的研报只能重新建立基准，不跨过未知状态计算修订。

净利润绝对变化保留原单位；比例变化使用上一值绝对值作分母，上一值为0时不计算比例，不引入可调的分母下限。缺失当前值或上一值单独给出原因。EPS仍须同一股份口径的额外依据；字段和目标期相同不证明拆股等因素不存在，缺少依据时不得认证EPS修订。

原始预测小数与身份指纹不经过二进制浮点。派生的变化比例和目标价中点使用64位有效数字、half-even舍入的独立小数上下文；这不把有限精度比例说成无限精度。EPS依据标识只用于核对调用方所给的股份口径是否相同，不能自行认证该依据；当前命令入口不接受该项推断，EPS修订保持未认证。

同一版本的重复观察只使用最早合格观察参与状态推进，同一时点按稳定的原始指纹选取代表。修订行保留所选当前/前一版本及相关响应指纹；全部重复采集的原始响应、观察时间和行映射另保留在观察包中，不宣称一行修订包含所有重复采集历史。

本合同不规定买卖方向、窗口、ETF权重或盈利标准。它产生可以检查的事件与匹配状态，任何后续真实因子研究都需要新的来源审查及专门准入。一般研究预算保持0，原诊断和股票预筛额度不复用。

## 验收

必须覆盖预测期保留、机构与作者切换、输入重排、完全重复、同身份冲突、同日歧义、迟到旧报告、更正与新报告区别、批量首次观察、原始小数、缺失与零分母、时区和更新时间矛盾，以及缺失EPS股份口径。验证仅证明这些行为，不证明来源完整、信号有效或净盈利。

## 独立离线入口

`scripts/review_analyst_observations.py`接入新事件和修订模块。它只读取明确给出的本地原始响应，不调用提供商适配器，不恢复旧规范化缓存中的缺失字段，也不切换旧股票预筛默认流程。

输入清单只包含以下结构；响应路径相对于清单所在目录解析，指纹绑定原始字节，观察时间必须带时区：

```json
{
  "schema_version": 1,
  "source": "tushare_report_rc",
  "captures": [
    {
      "path": "original_response.json",
      "sha256": "<原始响应的64位小写SHA-256>",
      "observed_at": "2024-01-03T10:00:00+08:00"
    }
  ]
}
```

```powershell
python scripts/review_analyst_observations.py --manifest <清单.json> --as-of <带时区截止时间> --output-dir <新目录>
```

清单最多128次观察、1MB；单份原始响应最多8MB、输入响应合计最多64MB。这些是资源边界，不是研究取样参数。校验发生在创建输出之前；晚于截止时间的原始文件不打开、不导出，报告日当日尚未达到可用时间的事件不进入导出的事件或修订表。成功的空响应单独计数，不能据此认证无报告。

新目录保存原始字节、可相对路径重放的`manifest.json`及`review.json`。原始分页字段`has_more`和`count`保留，3000条上限及有后续页的情况单独告警；`count`不冒充实际行数。所有采集都仍标记完整性未认证。

最后逐文件核对写出指纹，再通过更名放入`result.json`完成标记；中途写入失败没有完成标记，已有目录不覆盖、不自动续写。该机制验证本地写出及重放，不是断电持久性或独立时间戳认证。各产物继续处于项目忽略的数据目录，原始响应不上Git。

## 本次验证结果

新增54项测试：事件规范化22项、修订匹配20项、离线观察包12项。连同相关旧来源、配额和预筛检查，共109项通过；其后仅修改旧候选的目标价所需字段说明，对应9项检查再次通过。离线包测试包含真正的命令子进程、原始字节核对、自包含清单重放、截止时间隔离和写入失败，不把这些合成测试当作真实向前观察。

项目审计检查3177份文件通过，可维护性检查通过既有基线。证据入口为`data/reports/etf_monetization_20260911/analyst_event_identity_20260914/verification.json`。本次真实研报请求、ETF收益读取、新增向前观察日均为0。旧股票预筛未被该入口替代或追认；下一步是ETF汇总的机制、来源与身份准入审查。
