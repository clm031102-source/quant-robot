# 高管实际增持信息：来源组成评审

本轮转向一个新的来源提议：公开披露的管理层自有资金购买，是否包含随后仍未充分反映的公司信息，并能通过当时ETF暴露形成可交易信号。它与按成交量猜测资金流有概念区别，但尚未证明独立收益、国内适用性或ETF层面的优势；不选个股交易，不生成因子，也不恢复预算。

限定检索没有在`configs`、`docs/research`及现有因子目录找到holdertrade、insider、董监高、内部人、股东增减持或高管增持的匹配。这不是全部历史研究已查重的证明。来源检索限制为3个查询及3个主要页面访问目标，未调用数据接口或下载市场数据集；文档示例和搜索摘要中的历史及2026持股/价格示例可见，未用于制定阈值或评判绩效，ETF留出仍未打开。

[Lakonishok和Lee的NBER摘要](https://www.nber.org/papers/w6656)讨论美国1975—1995年的内部人交易，区分总体市场预测与个股横截面结果，并说明后者主要由较小公司驱动。正文页面访问出错，本轮只掌握检索返回的摘要，不声称复现论文。美国结果不能直接证明中国宽基ETF可盈利，也不能把内部人交易当天的价格当成公众收到披露后能成交的价格。

## 现有字段能证明什么

[Tushare官方字段说明](https://tushare.pro/wctapi/documents/175.md)提供公告日期、股东类别、增减持标记、数量、均价及可选的起止日期。这里未列出变动原因、具体交易方式、公告原件链接或修订链，数量栏也没有明确单位说明。不能仅凭`G`、`IN`和正数量，就把所有记录认证为高管自愿在二级市场支付现金买入；也不能未经核对直接按“万股”换算。

| 需要区分的问题 | 当前来源限制 |
| --- | --- |
| 自愿现金购买与其他持股增加 | 需明确变动原因/交易方式及原披露，不能用增持标记替代 |
| 交易发生与公众可知 | 开始、结束、公告、填报及首次公开时间分别保留；不能用交易开始日回填信号 |
| 计划、进展、最终实施与更正 | 同一事项需稳定身份和去重，不能把累计进展多次计为新增购买 |
| 数据完整性 | 空记录不是零购买；需核对覆盖、分页、单位和更正情况 |
| ETF对应暴露 | 需当时有效的成份或其他明确经济映射；现有指数名称映射不能代替历史成份权重 |

[上交所公开持股变动栏目](https://www.sse.com.cn/disclosure/credibility/supervision/change/)的检索呈现包含变动原因、变动日期和填报日期；页面说明这些信息由上市公司自行填报，股票数量单位为股。当前网页读取只得到栏目说明，没有历史行，不能把它视为已取得数据或“历史没有事件”。填报日期也还不是已经认证的首次公开时刻。

## 决定与下一条证据

不准入“直接过滤Tushare高管增持后求和”的简化信号。初始评审后的来源核对需要官方查询/字段说明，以及一个能区分购买、其他股份增加、事件日期和公开日期的限定原始记录；这属于来源组成核对，不是读取ETF收益。后续实际取件结果见下文，不再沿用初始的“尚未请求”状态。

如无法证明交易性质、可知时点或历史ETF映射，就挂起此提议；不改用所有个人/公司股东、另一期限或另一符号救回。即使字段齐备，仍须解释为何公开后有剩余信息、与旧价格反转机制有何区别，以及1000元持仓和费用能否承受，然后独立预注册。本轮不设收益阈值、不宣称统计通过、不建设专属交易模块。

限定范围和证据索引位于`data/reports/etf_monetization_20260911/trial_lineage_20260913/insider_review_scope.json`及`insider_review_result.json`。主预算仍为0，新增真实向前天数0。

## 限定取件后的决定

上交所栏目单次HTTP请求超时，未取得脚本或事件行。另读一份603511的2024年中报解析文本，能看到期内二级市场购买的汇总原因，但没有逐笔交易日期；PDF页图读取失败，未作视觉核验。报告中的期后解锁日期属于另一事项，不能代替购买日期。此期间报告路径对恢复逐事件时点已停止，不再扩读更多定期报告。

[Tushare公告接口说明](https://tushare.pro/wctapi/documents/176.md)提供原件链接、公告日期及可选的发布时间字段，因而限定核对002683.SZ、2021-07-02的公告元数据。第一次经本机代理超时，只能归为网络失败；随后相同公开文档的代理/直连比较，以及不带凭据的官方API检查，证明单次直连可以到达这些地址。直连使用现有凭据得到明确的40203权限拒绝，停止该接口，不购买或申请试用。本机网络设置和TLS验证没有修改。

另一条搜索定位到的巨潮历史PDF地址直连返回404，未取得原件。它只是未经原件认证的定位线索，不能据此断言该公司发生了购买，也不能说巨潮全部历史来源不可用。该提议当前挂起，重启需要新的可核对官方事件定位或现有公告权限的实质变化，不重复上述地址和接口。

公开时点要求按具体策略设计确定：可信的“截至某日公众已可知”日期，配合事前固定的保守延迟，可能已经足够；不一律要求精确到秒或全球最早发布。但交易发生日期、报告期末和后来补录日期仍不能互相替代。当前没有合格逐事件输入，也未认证历史ETF经济暴露。

后续取件与网络比较记录位于`data/reports/etf_monetization_20260911/insider_event_source_20260913/`。公开文档首次内容检查误读了尚未解压的gzip字节；离线解压后字段相符，已保留纠正记录，不能把这个诊断错误解释成来源不匹配。上述网络证据也促成政策不确定性来源的重新限定取件，结果单独记录。
