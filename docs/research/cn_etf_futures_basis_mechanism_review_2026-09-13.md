# 股指期货基差：收敛与ETF收益分开判断

本轮不准入“期货贴水就买入ETF”的提议。原始基差混合分红、融资和交易约束；到期收敛本身不能证明只持有ETF有正收益。衍生品隐含分红增长具有不同的信息含义，保留为有条件的方法与来源提议，但正文、国内同步报价和ETF账户映射尚未齐备，不恢复研究预算。

## 原始研究实际说明什么

Cao等人的《The emotional cost-of-carry》使用2010—2019年沪深300现货与IF收盘信息，将情绪、利率和股息率用于解释隐含折现率及基差。其式(3)—(4)定义基差为`S-F`；预测对象不是ETF下一期回报，不能倒转回归方向。第6页的数据口径和第12页的方程已直接查看PDF。月度变量标为上月也不足以认证发布时间或PCA训练范围。[大学原文](https://www.acem.sjtu.edu.cn/ueditor/jsp/upload/file/20230705/1688558895949073353.pdf)，[作者机构记录](https://research-portal.uu.nl/en/publications/the-emotional-cost-of-carry-chinese-investor-sentiment-and-equity/)

Golez的2014年研究从期货与期权联合提取前瞻分红信息，用于修正历史股息价格比。作者附录OA.2要求相配的期限，说明外部利率代理不能简单替代联合推算；OA.3讨论报价不同步，OA.5讨论交割时点和早期流动性。附录已取得并查看第3—4页，但它不是正文，不能据此声称完整复现。海外预测结果也不是本项目的净收益证据。[作者摘要](https://www.benjamin-golez.com/)，[作者在线附录](https://www.benjamin-golez.com/_files/ugd/cbc806_685a253f54a24e12acef30a241e4a2d9.pdf)

《Short-Term Basis Reversal》的作者摘要研究相邻期限期货的回报价差，不等于现货减期货的价格差；涉及两个期货头寸的收益不能归给一只ETF。这里只读了摘要，未取得正文。该页面最后修订于2026年5月，属于已接触的方法背景，不能宣称相关上下文完全盲态。[作者SSRN页面](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5250499)

## 七项合成机制核对

这些是精确十进制算术反例，不是行情回测、因子测试或原论文复现。假设和完整数字保存在本地`futures_basis_20260913/mechanism_checks.json`。

| 问题 | 核对结果及含义 |
| --- | --- |
| 贴水是否就是额外收入 | 假设现货10、期货9.8、现金分红0.2、到期现货9.8，现货含分红总收益恰为0 |
| 小额持仓费用是否可以忽略 | 上例买入100份，按每边万五且最低5元情景完整进出，1000元本金净亏10元；最低费仍待实际核实 |
| 收敛是否保证ETF赚钱 | 同样初始价格和分红，两价可以在9元收敛而现货总收益为负；反例否定保证，不否定所有统计预测可能 |
| 原始基差能否分离融资和分红 | 现货100、期货98，同时容许折现因子1/分红现值2，或折现因子0.99/分红现值2.98，单凭两价无法识别 |
| 期权增加了什么信息 | 在同标的、同到期、同交割的无摩擦欧式模型中，两个行权价的认购减认沽价差可识别折现因子 |
| 一组平值期权是否足够 | 行权价等于期货价格时，理论认购减认沽价差为0，对任何折现因子都一样，无法唯一识别 |
| 为什么报价质量是先决条件 | 假设期货减行权价仅0.1，配对价格误差0.01就会造成折现因子误差0.1；不能随意用最后成交价填充同步报价 |

最后三项仅在声明的理想模型中将期货近似远期，忽略融资随机性、逐日盯市、报价摩擦和交易约束；不把这个简式部署成真实估计器。分红的现金支付、税额和ETF跟踪差异也不能直接套用这些假设。

## 国内来源与旧配置的实质缺口

旧[期权情绪来源配置](../../configs/cn_etf_option_sentiment_source_readiness_20260728.json)仅覆盖SSE/SZSE ETF期权的身份及日活动，且9只标的不足原30只横截面门槛。它不含行权价、完整交割条款或同步买卖报价，不能当作新估值模型的数据资格，也不能借此次提议降低旧门槛。

供应商当前`opt_basic`文档提供行权价、单位和到期等字段，其中行权价/单位注明经过除权除息调整；这不等于已有历史版本。`opt_daily`文档虽列CFFEX，字段是日线、结算、量额与持仓，没有同步盘口及报价时间戳。本轮只读接口说明，没有发起市场数据请求，未核实当前账户的具体权限。[合约文档](https://tushare.pro/document/2?doc_id=158)，[日线文档](https://tushare.pro/document/2?doc_id=159)

中金所的股指期权规则提供欧式行权、现金交割及到期条款线索，但本次正文打开超时，仅核对搜索可见条款；不同年代的完整有效版本仍未认证。ETF期权和股指期权的标的、分红及交割方式不能混用，结算价也不能默认等于同时刻现货收盘。[交易所规则](https://www.cffex.com.cn/cn/ssxz/20221214/43100.html)

因此，前瞻分红提议要重新评审的最小材料为：完整可复核方法、同一指数的合约和交割身份、可配对历史报价及时间、分红口径与风险溢价解释、随后ETF持有收益的机制和费用适配。价格可下载不自动满足这些条件；推算出的风险中性信息也不自动等于真实世界的收益期望。
