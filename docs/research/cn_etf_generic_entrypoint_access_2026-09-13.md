# CN_ETF 通用研究入口准入修复

2026-09-13，office_desktop，factor_review。当前主研究预算为0、2026收益留出封存；本次仅用示例和合成数据复现工程问题。

## 问题与修复

通用研究、信号、模拟、批量实验和滚动验证命令原先只对CN股票校验启动、数据清单及就绪材料。选择CN_ETF时会跳过这些股票检查，随后读取行情；日期过滤发生在读取之后。旧股票材料和轮动成员配置都不能证明ETF的来源、预注册、试验次数或留出授权。

新增统一准入函数，在下列命令的行情加载前拒绝未经专门入口绑定的CN_ETF及ALL请求：

| 命令 | 拒绝位置与范围 |
| --- | --- |
| run_research_pipeline | processed-bars加载前，先于股票材料校验 |
| run_signal_snapshot | 公共函数及内部加载函数，先于持仓、行情和输出 |
| run_paper_simulation | 公共函数及内部加载函数，先于持仓、行情和输出 |
| run_experiment_grid | 配置解析后及内部加载函数；混合市场列表整体预检查 |
| run_walk_forward | 配置解析后及内部加载函数；同时覆盖processed-bars和authority-bars |

混合选择如US、CN_ETF必须在读取第一份US行情之前拒绝。ALL在通用命令中按包含ETF处理，不能成为绕过路径。大小写和前后空白不会避开保护。未增加跳过开关，也不签发新的研究授权。

fixture仍使用内置演示数据；CN股票原有校验及其他市场加载行为保留。两个旧轮动测试改为以合成行情直接检验核心算法及成员配置，不再把通用ETF入口成功当作预期。核心计算函数仍供合格专门入口与合成测试使用，本次未将它们认证为可自行授权的研究入口。

## 验证与影响

合成最小复现先发现三类缺口：研究加载器未拒绝；两个多市场加载器未先检查完整选择；authority-bars先接触来源配置检查而没有ETF准入。修复后新增11项测试通过，其中6次实际命令行子进程使用临时配置和不存在的数据路径，均在输出生成之前明确拒绝。

另有72项相关既有测试通过，合计83项不同测试：信号/模拟及研究加载10项、批量实验/滚动验证17项、每日运营/模拟批次/参数选择/工厂34项、约束候选与桌面验证11项。前期7项新增测试是最终11项的子集，不重复计数。全部采用示例、临时合成数据或明确替身；不读取真实ETF收益。

调用链检查确认工厂、每日运营、模拟批次、参数选择、约束候选和桌面验证在调用上述入口重新生成结果时会受到保护。其中批次可能将拒绝记为失败条目；不声称整个批次在任何元数据读取前退出。既有结果复用路径独立存在，本次没有认证旧候选、晋级材料或其复用资格。

本地证据保存在`data/reports/etf_monetization_20260911/cli_research_access_20260913/`，不提交生成数据。该修复不增加研究预算，不产生新因子、市场收益检验或真实向前模拟日，也不改变券商与交易边界。
