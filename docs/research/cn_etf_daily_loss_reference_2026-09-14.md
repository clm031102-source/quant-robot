# 日亏损基准与隔夜损失

## 已核实的差异

旧离线准入将每次会话开盘权益作为当天亏损基准；历史账户风险审计按相邻日估值比较。两者不是相同的风险口径。合成复现中，现金9010元、200份由4.95元变为次日4.455元，账户权益减少99元；旧离线模式将次日开盘权益重设为9901元，日亏损显示0，未触发60元限制。前一观察不是已认证的官方收盘价，这个案例仅证明开盘重设会漏掉两次观察之间的损失。

现新增明确选择的v2策略字段 `daily_loss_basis: "previous_session_close_v1"`。默认行为和既有配置指纹不变；该选择与敞口减仓模式分别冻结，不能在运行中更改。

## 新模式的固定合同

1. 首个配置交易日的首次开盘以当时账面权益起算，并明确标记 `first_session_open`；不把这项起算声明当作更早持仓的完整损益证据。
2. 后续交易日必须引用配置日历中紧邻前一个交易日的已记录收市观察。缺失、跨过一个应观察交易日或策略指纹不符，拒绝新会话准入，不能改用当天开盘或更早估值兜底。
3. 收市观察固定为上海时间15:00:00至15:00:30内第一份有效账面估值。上下文时间不能早于15:00，报价与上下文时效上限均不得超过30秒；保留原报价验证。尚有未结委托、账户差额或未解决故障时不认证收市观察。后续价格变化不会覆盖已选基准。
4. 这一基准是合成报价中间价对应的账面权益，明确没有认证为交易所官方收盘价。现金账户、停牌、没有报价及当前交易规则的实际适用性仍要按具体来源审核；不把旧日线价格改标签送入该模式。
5. 次日开盘立即按该基准检查60元日亏损；准入、发送和连续估值共同使用它，并继续计入未决费用。`book_loss_from_open`保留开盘以来的含义，`projected_daily_loss`包含隔夜变化和费用，二者不混为一谈。
6. 基准与原估值同一日志事务提交。保存事件序号、上下文时间和日志锚点；实际子进程在提交前退出不会留下半份基准，提交后重开能恢复。晚到成交和权益更正继续保留原有账本及更正限制，不因此认证实际成交日归因。

这一模式修复可观测的隔夜损失漏检，不保证真实损失一定小于60元；跳空、停牌、不可卖及执行延迟仍可能导致超过阈值后的暂停。每日亏损触发全面暂停，敞口减仓模式不能绕过它。8%累计回撤继续跨日保留。
