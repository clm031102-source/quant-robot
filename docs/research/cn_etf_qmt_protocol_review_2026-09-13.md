## 已实现的限定缺口

新增[离线回报核对](../../src/quant_robot/execution/offline_qmt_receipts.py)和[场景测试](../../tests/unit/test_offline_qmt_receipts.py)。函数只接受显式合成范围及字典/list，不含传输、SDK依赖、数据库写入或重试操作；现有运行器不会自动导入或执行它。

- 将48—57和255状态与项目状态区分，未知值保留为UNKNOWN。部分成交待撤不会映射为终结。
- 按声明的账户别名、日期、市场、订单/合同及买卖方向核对单笔范围。备注不会覆盖身份冲突；日期是外部提供的合成日期，未获原始捕获时点认证。
- 同一成交编号的相同事实只计一次，冲突事实报错。状态累计量高于明细时标记缺成交，低于明细时标记快照落后；不从均价和累计量制造一笔成交。
- 只声明回报数量是否相合。成交金额保留原始值加总，不认证报价精度、费用、可用现金或可售份额；不把金额默认为扣费净额。
- 即使数量相合，`executable`、`accounting_verified`、`reservation_release_allowed`、`automatic_retry_allowed`均为false。部分成交后的最终撤销必须继续经过完整费用、资金、持仓和日志核对。

非空柜台合同号、字段齐全等是本原型的保守入口条件；缺失字段的早期消息或其他版本须留待补齐，不能用备注猜配。测试中的账户类型数字只是合成数据，不是具体券商枚举认证。尚未确认的金额精度、时钟、回报完整性和账户类型均列入函数输出的集成缺口。

新增16项测试覆盖上述核心风险；相邻派发、接口边界和订单日志54项回归通过，合计70项。首次新增测试因模块尚未实现失败，完成实现后通过；一次回归命令误写日志测试模块名产生加载错误，随后按实际文件名完成其28项测试，已通过的42项未重复运行。旧接口测试有文件未显式关闭的ResourceWarning，本轮未扩大修改该历史测试。项目审计通过；这些证据不能代表真实券商联调或前向盈利。

## 具体接入包还缺什么

| 缺口 | 下一条决定性证据 |
| --- | --- |
| 券商及产品选择、模拟权限 | 用户已有券商及官方开通条件；实际MiniQMT模拟环境、支持ETF列表和账户隔离证明 |
| 版本与凭据 | 券商提供的客户端/SDK固定版本、依赖与枚举说明；独立授权后才在隔离环境安装与验证，秘密不入Git |
| 报价和订单语义 | 已授权的账户适用整手/最小价位、限价/有效期、状态、限频、交易日边界与回报时间编码 |
| 成交到账 | 真实回报样本及正式费用、税费、精度、资金/可售份额时点；跨日查询和断线恢复覆盖 |
| 幂等及日志衔接 | 在确认投递结果不明时停止新风险；准确关联本地意图、请求、订单与明细，再接入现有日志。备注和超时重发不能代替这条链路 |
| 开始实盘的前置验收 | 独立研究准入和冻结检验、真实前向模拟、适用报告手续、人工监督和明确的范围变更授权 |
